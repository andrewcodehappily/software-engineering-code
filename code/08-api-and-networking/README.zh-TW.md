<a name="article-11001"></a>

### 第 11001 條【契約沉默】

未記載於文件之 API 回應，不因曾出現兩次而取得契約效力。

<a name="article-11002"></a>

### 第 11002 條【狀態碼管轄】

回應標示 200 者，不當然證明請求之操作成功。

<a name="article-11003"></a>

### 第 11003 條【逾時救濟】

無限等待回應之 Client，得於合理逾時後終止程序。

<a name="article-11004"></a>

### 第 11004 條【重試比例原則】

失敗之 Request，不得以足以引發第二起事故之頻率重試。

<a name="article-11005"></a>

### 第 11005 條【冪等保障】

重複 Request 不因首次回應遺失而取得向客戶重複收費之權力。

<a name="article-11006"></a>

### 第 11006 條【DNS 歸責】

改用其他語言重寫應用程式前，得先調查 DNS。

<a name="article-11007"></a>

### 第 11007 條【限流承認】

Client 收到 429 時，不得將之解讀為更加努力之鼓勵。

<a name="article-11008"></a>

### 第 11008 條【Localhost 主權】

localhost 所指者為發出 Request 之機器，而非開發者主觀期待之機器。

<a name="article-11009"></a>

### 第 11009 條【版本條約】

違反已公開契約之 API，不得僅藉重新命名 Endpoint 規避審查。

<a name="article-11010"></a>

### 第 11010 條【快取證人】

Cache 所保存之回應得證明過去，不得推定為現在之狀態。
