# 第二編　Bug 管理法

[English](README.md) · [返回上層](../README.zh-TW.md) · [總目錄](../../README.zh-TW.md)

### 第 404 條【失蹤錯誤】

經查無法找到之 Bug，不得推定其已不存在。

### 第 500 條【責任歸屬】

在尚未完成調查前，前端與後端均有權合理懷疑對方。

### 第 743 條第 928 項【不可重現錯誤豁免條款】

若 Bug 無法穩定重現，且目前所有功能皆正常，則禁止繼續修改程式，以免製造更多可穩定重現的 Bug。

### 第 744 條【錯誤繁殖定律】

修復一項 Bug 後新增之 Bug，不得視為原修復工作之附屬成果。

### 第 745 條【觀測者效應】

若 Bug 於工程師開始錄影、截圖或展示時立即消失，應列為量子級 Bug，並依法暫停調查。

### 第 746 條【重啟特赦】

經重新啟動後消失之非重大錯誤，得暫予結案，但應保留其再次犯罪之可能性。

### 第 747 條【日誌觀測】

Bug 因新增日誌而消失者，該日誌得作為證據，但不得認定為修復證明。

### 第 748 條【重複報案】

重複回報之案件經結案者，不因此減少受影響之使用者人數。
