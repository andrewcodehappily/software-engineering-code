# 第五編　測試與部署法

[English](README.md) · [返回上層](../README.zh-TW.md) · [總目錄](../../README.zh-TW.md)

### 第 10001 條【測試通過之效力】

所有測試均通過，僅能證明所有已撰寫之測試均通過。

### 第 10002 條【星期五部署限制】

非因重大緊急事故，不得於星期五下班前部署重大更新。違反者，視為自願放棄週末。

### 第 10003 條【使用者不可預測性】

工程師不得假定使用者將按照工程師所預期之方式使用軟體。即使該使用方式明顯不符合人類正常邏輯，亦同。

### 第 10004 條【測試環境獨立】

測試環境之成功判決，不拘束正式環境。

### 第 10005 條【不穩定測試證詞】

未修改程式碼而反覆通過及失敗之測試，於調查完成前列為不可靠證人。
