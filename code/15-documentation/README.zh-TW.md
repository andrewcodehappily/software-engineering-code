<a name="article-18001"></a>

### 第 18001 條【範例效力】

文件中之 Example 視為公開承諾，應接受合理測試。

<a name="article-18002"></a>

### 第 18002 條【過期指示】

指向三個版本以前已移除按鈕之說明，得適用快速修正程序。

<a name="article-18003"></a>

### 第 18003 條【註解理由】

說明決策理由之 Comment，不得僅因實作可見而認定為多餘。

<a name="article-18004"></a>

### 第 18004 條【TODO 時效】

未載明負責人或日期之 TODO，得持續待辦至原作者忘記其存在。

<a name="article-18005"></a>

### 第 18005 條【README 管轄】

README 應先引導讀者至相關文件，不得先要求閱讀整個 Repository。

<a name="article-18006"></a>

### 第 18006 條【安裝可重現性】

Setup Guide 不得推定讀者持有僅存在於作者電腦之文件。

<a name="article-18007"></a>

### 第 18007 條【術語效力】

既有技術術語於翻譯可能造成混淆時，得保留其英文拼寫。

<a name="article-18008"></a>

### 第 18008 條【圖表準確性】

Architecture Diagram 不得僅因配色已更新而宣告內容為最新版。

<a name="article-18009"></a>

### 第 18009 條【Changelog 範圍】

Changelog 記載「其他改善」者，不得阻止讀者要求具體內容。

<a name="article-18010"></a>

### 第 18010 條【文件繼承】

所描述之系統已分歧者，複製文件不得繼承原始文件之真實性。
