# Part 3 — Code and Technical Debt

[繁體中文](README.zh-TW.md) · [Section index](../README.md) · [Master index](../../README.md)

### Article 1024 — Protection of Historical Code

Unclaimed code whose purpose is unknown but whose removal causes system failure shall be designated a protected historical monument.

### Article 1025 — Authority of Comments

Where comments conflict with executable behavior, the latter shall prevail.

### Article 2048 — Technical Debt Extensions

Technical debt may be deferred on the grounds that it will be addressed in the next release. No limit shall apply to such extensions.

### Article 4096 — Proportionality in Refactoring

The removal of three lines of code shall not, by itself, justify the introduction of four classes, six files, and two external dependencies.

### Article 1026 — Commented-Out Antiquities

Code retained exclusively in comments shall be eligible for relocation to the archives of Git history.

### Article 1027 — Naming Proceedings

The time spent naming a variable shall not be presumed proportional to the length of its name.
