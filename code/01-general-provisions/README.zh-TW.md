# 第一編　基本法

[English](README.md) · [返回上層](../README.zh-TW.md) · [總目錄](../../README.zh-TW.md)

### 第 1 條【正常運行保護原則】

凡能正常運行之程式，非有充分理由，不得擅自修改。

### 第 2 條【本機正常原則】

工程師得以「在我電腦上可以正常運行」作為初步抗辯理由，但不得據此宣告案件終結。

### 第 3 條【功能推定原則】

任何未經文件記載之程式行為，在尚未造成重大損害前，得暫時認定為未公開功能。

### 第 4 條【臨時方案永久化】

以臨時性質部署之解決方案，若持續運行超過一年，應自動取得正式基礎設施之地位。

### 第 5 條【完成之定義】

功能不得僅因開發者停止查看，即認定為已完成。

### 第 6 條【簡單之認定】

凡稱需求簡單者，應附具規格；未附者，視為樂觀意見。
