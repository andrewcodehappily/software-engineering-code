<a name="article-13001"></a>

### 第 13001 條【信心證據】

模型對答案之信心，不得作為答案正確之獨立證據。

<a name="article-13002"></a>

### 第 13002 條【Prompt 修正】

Prompt 僅修改三個字者，仍可能構成輸出行為之重大修正。

<a name="article-13003"></a>

### 第 13003 條【引用審查】

模型產生之引用，應先審查其是否存在，再審查其權威性。

<a name="article-13004"></a>

### 第 13004 條【Benchmark 管轄】

模型於單一 Benchmark 勝出者，不因此取得所有智力活動之管轄權。

<a name="article-13005"></a>

### 第 13005 條【Context 邊界】

未納入模型 Context 之文件，不得僅藉立法宣告視為已閱讀。

<a name="article-13006"></a>

### 第 13006 條【生成程式碼】

AI 生成之 Code，應適用與匆忙撰寫程式之人類相同之 Review 程序。

<a name="article-13007"></a>

### 第 13007 條【Token 預算】

要求精簡回答者，不得據此授權以整個 Context Window 撰寫前言。

<a name="article-13008"></a>

### 第 13008 條【評估獨立】

已取得測試答案之模型，不得被指定為該測試之唯一評審。

<a name="article-13009"></a>

### 第 13009 條【Tool 證詞】

Tool 尚未回傳成功證據前，不得宣告其操作完成。

<a name="article-13010"></a>

### 第 13010 條【人工審查】

AI-assisted 之字樣，不得將已部署變更之責任移轉予不具法律人格之伺服器。
