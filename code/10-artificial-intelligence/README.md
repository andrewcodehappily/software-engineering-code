<a name="article-13001"></a>

### Article 13001 — Confidence Evidence

A model's confidence in an answer shall not constitute independent evidence of its correctness.

<a name="article-13002"></a>

### Article 13002 — Prompt Amendment

A change of three words in a prompt may constitute a substantial amendment to the resulting behavior.

<a name="article-13003"></a>

### Article 13003 — Citation Examination

A citation generated by a model shall be examined for existence before being examined for authority.

<a name="article-13004"></a>

### Article 13004 — Benchmark Jurisdiction

A model prevailing on one benchmark shall not thereby acquire jurisdiction over all intellectual activities.

<a name="article-13005"></a>

### Article 13005 — Context Limits

A document outside the context supplied to a model shall not be deemed read by legislative declaration.

<a name="article-13006"></a>

### Article 13006 — Generated Code

AI-generated code shall be subject to the same review as code authored by a human who was in a hurry.

<a name="article-13007"></a>

### Article 13007 — Token Budget

A request for a concise response shall not authorize the expenditure of an entire context window on introductions.

<a name="article-13008"></a>

### Article 13008 — Evaluation Independence

A model shall not be appointed sole judge of a test whose answers it has already received.

<a name="article-13009"></a>

### Article 13009 — Tool Testimony

A tool operation shall not be declared successful before the tool returns evidence of success.

<a name="article-13010"></a>

### Article 13010 — Human Review

The words AI-assisted shall not transfer responsibility for a deployed change to a server with no legal personality.
