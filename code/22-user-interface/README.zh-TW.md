<a name="article-25001"></a>

### 第 25001 條【隱形按鈕】

須經會議說明始知存在之 Button，得列入可發現性 Review。

<a name="article-25002"></a>

### 第 25002 條【色彩證詞】

不得僅以色彩作為區別成功與失敗之唯一證據。

<a name="article-25003"></a>

### 第 25003 條【鍵盤通行權】

以鍵盤操作之使用者，不得被視為 UI 之未授權訪客。

<a name="article-25004"></a>

### 第 25004 條【Loading 狀態】

Spinner 持續顯示者，不足以證明有效工作仍無限進行。

<a name="article-25005"></a>

### 第 25005 條【破壞性操作】

破壞性操作應於傳喚使用者滑鼠作證前，明確與一般導覽操作區別。

<a name="article-25006"></a>

### 第 25006 條【Responsive 管轄】

UI 不因視窗小於設計者螢幕即免除其義務。

<a name="article-25007"></a>

### 第 25007 條【Error Message】

記載發生錯誤之 Message 無須揭露機密，惟可行時宜提供有用之後續步驟。

<a name="article-25008"></a>

### 第 25008 條【Focus 秩序】

Focus 應依有意義之順序移動，不得無故遊覽整頁。

<a name="article-25009"></a>

### 第 25009 條【空狀態】

Database 確無符合紀錄者，不得將空 List 推定為故障。

<a name="article-25010"></a>

### 第 25010 條【在地化】

翻譯後之 Label 應有適當空間，不得截斷至產生其他法律意義。

<a name="article-25011"></a>

### 第 25011 條【動畫節制】

Animation 不得僅因外觀華麗即取得延遲所有日常操作之權力。

<a name="article-25012"></a>

### 第 25012 條【使用者控制權】

使用者明確儲存之 Preference，不得因重新設計發現新偏好預設值而默默撤銷。
