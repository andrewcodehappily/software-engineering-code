<a name="article-25001"></a>

### Article 25001 — Invisible buttons

A button whose existence must be explained in a meeting shall be eligible for a discoverability review.

<a name="article-25002"></a>

### Article 25002 — Color testimony

Color alone shall not be the sole witness distinguishing success from failure.

<a name="article-25003"></a>

### Article 25003 — Keyboard access

A user operating by keyboard shall not be treated as an unauthorized visitor to the interface.

<a name="article-25004"></a>

### Article 25004 — Loading state

A spinner shall not constitute evidence that useful work continues indefinitely.

<a name="article-25005"></a>

### Article 25005 — Destructive action

A destructive action shall be clearly distinguished from an ordinary navigation action before the user's mouse is called to testify.

<a name="article-25006"></a>

### Article 25006 — Responsive jurisdiction

An interface shall not lose its obligations merely because its window is narrower than the designer's monitor.

<a name="article-25007"></a>

### Article 25007 — Error messaging

A message stating that something went wrong shall not be required to disclose secrets, but should provide useful next steps where possible.

<a name="article-25008"></a>

### Article 25008 — Focus order

Focus shall travel in a meaningful order rather than conducting an unexplained tour of the entire page.

<a name="article-25009"></a>

### Article 25009 — Empty state

An empty list shall not be presumed broken when the database legitimately contains no matching records.

<a name="article-25010"></a>

### Article 25010 — Localization

A translated label shall be permitted sufficient space to exist without being truncated into a different legal meaning.

<a name="article-25011"></a>

### Article 25011 — Motion restraint

An animation shall not be granted authority to delay every routine operation merely because it looks impressive.

<a name="article-25012"></a>

### Article 25012 — User control

A preference explicitly saved by a user shall not be silently revoked because a redesign has discovered a new favorite default.
