# 軟體工程師法典

[English](README.md) · [返回總目錄](../README.zh-TW.md)

版本：v0.0.2-alpha

本法典依[軟體工程師憲法](../constitution/README.zh-TW.md)制定；於本虛構法制內，如與憲法牴觸，應以憲法為準。

立法宗旨：保障程式之正常運行、工程師之精神健康，並防止修復行為本身成為事故來源。

本法典純屬諷刺娛樂，不具法律效力，亦非工程作業規範。安全、資安、資料完整性及重大事故應依實際程序處理。
