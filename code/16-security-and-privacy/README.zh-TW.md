<a name="article-19001"></a>

### 第 19001 條【Secret 地位】

已 Commit 至公開 Repository 之 Secret，不因事後 Revert 而恢復秘密性。

<a name="article-19002"></a>

### 第 19002 條【驗證區別】

Authentication 成功者，不當然取得執行全部可用操作之權限。

<a name="article-19003"></a>

### 第 19003 條【最小權限】

讀取權限之申請，不得自動擴張為管理權限之授予。

<a name="article-19004"></a>

### 第 19004 條【Input 證詞】

User Input 不因透過美觀之 Form 提交而推定可信。

<a name="article-19005"></a>

### 第 19005 條【揭露程序】

Vulnerability Report 不得以公開 Secret 作為受理之必要條件。

<a name="article-19006"></a>

### 第 19006 條【Log 隱私】

調查事故之意願，不構成蒐集所有可得個人資訊之授權。

<a name="article-19007"></a>

### 第 19007 條【資安形式主義】

Security Control 應依其實際保護效果評估，不得僅依警告色彩之嚴厲程度評估。

<a name="article-19008"></a>

### 第 19008 條【Encryption 聲明】

Ciphertext 之外觀，不足以證明 Key 及 Plaintext 已受適當保護。

<a name="article-19009"></a>

### 第 19009 條【Patch 優先權】

已知重大 Vulnerability，不適用一般不可重現 Bug 之豁免。

<a name="article-19010"></a>

### 第 19010 條【資料保留】

資料將來可能有用之情形，不足以單獨正當化無限期保留。
