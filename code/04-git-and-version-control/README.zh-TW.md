# 第四編　Git 與版本控制法

[English](README.md) · [返回上層](../README.zh-TW.md) · [總目錄](../../README.zh-TW.md)

### 第 409 條【合併衝突】

合併衝突之發生，不代表任何一方有過失，但雙方均得於心中譴責對方。

### 第 8192 條【提交訊息真實性】

以 `final` 命名之提交，不具最終版本之法律效力。以 `final-final` 命名者，亦同。

### 第 8193 條【歷史追責】

工程師使用 `git blame` 查明責任人為過去之自己時，得依法行使緘默權。

### 第 8194 條【提交歸責】

最後一次提交之作者，不得當然負擔整個儲存庫所有缺陷之責任。

### 第 8195 條【暫存保管】

暫存逾一年者，推定含有不可替代之成果或毫無價值之內容；非經開啟，不得認定其屬何者。
