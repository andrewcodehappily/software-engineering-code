<a name="article-22001"></a>

### 第 22001 條【刑罰性質】

本虛構刑法之處分限於文件、Review、測試等無害工程補救措施，不授權真實刑罰。

<a name="article-22002"></a>

### 第 22002 條【非法確信罪】

未經任何驗證即宣告 Bug 已修復者，得命其重現原始回報。

<a name="article-22003"></a>

### 第 22003 條【偽造綠燈罪】

僅為取得綠色 Badge 而停用失敗測試者，不構成合法無罪判決。

<a name="article-22004"></a>

### 第 22004 條【證據滅失罪】

未記錄相關事實即刪除有用 Diagnostic 者，得命重建調查；正當隱私及保留規範不在此限。

<a name="article-22005"></a>

### 第 22005 條【無照估時罪】

未諮詢實作者即強制設定 Deadline 者，得命參與估時程序。

<a name="article-22006"></a>

### 第 22006 條【身分混淆罪】

僅因某貢獻者頭像出現於 Commit 旁即歸責者，非有其他證據不得採納。

<a name="article-22007"></a>

### 第 22007 條【擅自擴張罪】

未揭露即將無關重寫夾帶於小型 Bug Fix 者，得命拆分變更。

<a name="article-22008"></a>

### 第 22008 條【文件偽證罪】

明知 Setup Guide 遺漏必要 Dependency 者，得命其於乾淨機器接受審判。

<a name="article-22009"></a>

### 第 22009 條【會議遞迴罪】

僅為安排下次會議而開會者，得以載明實際決定之 Calendar Invitation 補救。

<a name="article-22010"></a>

### 第 22010 條【重構未遂】

因測試失敗而放棄之 Refactor 提案，不得僅因曾經嘗試而受處分。

<a name="article-22011"></a>

### 第 22011 條【自首減免】

工程師及時通報自身錯誤者，應就其促成及時緩解之行為予以肯定。

<a name="article-22012"></a>

### 第 22012 條【更生程序】

已完成必要改善工作者，不得永久以過往事故之名稱稱呼之。
