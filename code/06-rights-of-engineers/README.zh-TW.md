# 第六編　工程師權利保障法

[English](README.md) · [返回上層](../README.zh-TW.md) · [總目錄](../../README.zh-TW.md)

### 第 65535 條【工期估算豁免】

工程師所稱「五分鐘就好」，不得作為任何具有約束力之時間承諾。

### 第 65536 條【需求變更】

凡以「順便加一個小功能」開頭之需求，不得僅依其字數判定工作量。

### 第 65537 條【文件請求權】

受命維護無文件系統之工程師，得請求提供文件，包括解釋何以不存在文件之文件。

### 第 65538 條【會議轉換權】

唯一成果為書面進度報告之會議，得直接轉換為書面進度報告，不生不利益。
