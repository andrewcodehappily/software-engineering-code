# 第三章　憲政秩序

[English](README.md) · [返回上層](../README.zh-TW.md) · [總目錄](../../README.zh-TW.md)

### 第 8 條【法律保留】

任何新增需求，非經正式程序，不得以「順便」二字強制施行。

### 第 9 條【違憲審查】

任何違反本憲法之 Pull Request，最高工程法院得予以駁回。

### 第 10 條【緊急狀態】

Production 發生重大事故時，得依法宣布緊急狀態，暫停一般開發程序。

### 第 11 條【修憲】

本憲法之修正應經 Pull Request 提出，並由具有合併權限之人員批准。

### 第 12 條【不可抗力】

因第三方 API、外部依賴或雲端服務故障所致之事故，不得逕行歸責於工程師。
