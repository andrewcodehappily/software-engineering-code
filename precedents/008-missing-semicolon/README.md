# SEC Case 008: The Missing Semicolon

[繁體中文](README.zh-TW.md) · [Section index](../README.md) · [Master index](../../README.md)

> Fictional illustrative precedent, not an actual GitHub case or legal judgment.

## Facts

One omitted semicolon generated dozens of diagnostics. The prosecution requested separate charges for each diagnostic.

## Reasoning

Article 21002 distinguishes a primary syntax defect from its cascading diagnostics. The number of diagnostic messages is not the number of independently established defects.

## Disposition

The charges are consolidated pending a fresh build. The missing semicolon is ordered to return to its original position.
