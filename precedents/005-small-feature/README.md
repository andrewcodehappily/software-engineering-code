# SEC Case 005: The Small Feature

[繁體中文](README.zh-TW.md) · [Section index](../README.md) · [Master index](../../README.md)

> Fictional illustrative precedent, not an actual GitHub case or legal judgment.

## Facts

A request described as one small feature required a database migration, new API and redesigned permissions.

## Reasoning

Article 65536 and constitutional Article 8 reject the use of short descriptions as binding estimates of scope.

## Disposition

The request is remanded for estimation. The adjective small is struck from the record.
