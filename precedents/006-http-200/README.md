# SEC Case 006: The Successful Failure

[繁體中文](README.zh-TW.md) · [Section index](../README.md) · [Master index](../../README.md)

> Fictional illustrative precedent, not an actual GitHub case or legal judgment.

## Facts

An API returned HTTP 200 with a response body stating that the operation failed.

## Reasoning

Article 11002 distinguishes HTTP status from the underlying business outcome.

## Disposition

The status code is acquitted of impersonating a business transaction; the API contract is ordered to clarify its behavior.
