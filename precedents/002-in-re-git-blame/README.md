# SEC Case 002: In re Git Blame

[繁體中文](README.zh-TW.md) · [Section index](../README.md) · [Master index](../../README.md)

> Fictional illustrative precedent, not an actual GitHub case or legal judgment.

## Facts

An engineer investigated a mysterious line of code and discovered that its author was the same engineer three years earlier.

## Reasoning

Constitution Article 5 and Code Article 8193 permit silence, but do not establish that authorship alone proves responsibility for every consequence.

## Disposition

The engineer may remain silent. The code remains subject to review.
