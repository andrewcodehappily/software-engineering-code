# Release 與部署施行細則

[English](README.md) · [返回上層](../README.zh-TW.md) · [總目錄](../../README.zh-TW.md)

本文件為虛構法制之施行文件，純屬娛樂，不取代實際工程規範。

## 第 1 條【頒布資格】

Release Candidate 不得僅因刪除 Candidate 字樣即取得 Stable 地位。

## 第 2 條【星期五例外】

星期五緊急部署應載明緊急事由及負責監控後果之人員。

## 第 3 條【Rollback 準備】

Rollback 程序應於成為組織內最急需之文件以前備妥。

## 第 4 條【頒布公告】

Release Notes 應區分已完成之變更、願望及意外留在 Roadmap 之事項。

## 第 5 條【部署監控】

部署後第一分鐘無人申訴，不構成勝利宣告。

## 第 6 條【Rollback 尊嚴】

有正當理由之 Rollback，不得視為侵害原作者名譽之罪行。
